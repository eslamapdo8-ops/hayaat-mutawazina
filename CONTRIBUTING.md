# Contribution Guidelines

Thank you for considering contributing to our project! We welcome contributions from the community and appreciate your help. Here are some guidelines to get you started.

## Getting Started
1. **Fork the repository**: Click on the 'Fork' button at the top right of the page to create a copy of the repository in your account.
2. **Clone the repository**: Use the following command to clone your fork of the repository:
   ```
   git clone https://github.com/<your-username>/hayaat-mutawazina.git
   ```
3. **Create a branch**: Before making any changes, create a new branch for your feature or bug fix:
   ```
   git checkout -b my-feature-branch
   ```

## Making Changes
- Make your changes in the new branch.
- Make sure to write clear and concise commit messages that provide context for your changes.

## Testing
- It's important to test your changes. Ensure that any tests you run pass successfully.

## Submitting Changes
1. **Push your changes**: After committing your changes to your branch, push them to your fork:
   ```
   git push origin my-feature-branch
   ```
2. **Create a Pull Request**: Go to the original repository and click on the 'New Pull Request' button. Select your branch and submit your PR.

## Development Setup
To set up the development environment, follow these instructions:
1. Ensure you have [Node.js](https://nodejs.org/) installed on your machine.
2. Clone the repository using the previous instructions.
3. Install the necessary dependencies:
   ```
   npm install
   ```
4. To start the development server, use:
   ```
   npm start
   ```

## Code of Conduct
Please adhere to our [Code of Conduct](link-to-code-of-conduct) in all your interactions in the community.

Thank you for your interest in contributing! We look forward to your contributions!
